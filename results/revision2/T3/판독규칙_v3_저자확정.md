# 용접 이미지 쌍 판정 규칙 (IR2605 판독용) — v3, 저자 확정 (2026-10-29)

> **정본.** 저자가 2차 판독에 실제로 적용한 규칙이다(저자 제공 원문 그대로). Claude의 판독도 이 규칙을 따른다(저자 지시, 10/29).
> 이전 판: `sheets_author/판독안내.md` v1(10/28)·v2(10/29)는 이 문서로 대체된다.
> ⚠️ §5 예시 12쌍(A06·A25·A40·A08·A28·A26·A29·A47·A30·A51·A57·A23)은 저자 판정이 규칙 안에 공개되어 있으므로,
> Claude가 이 규칙으로 다시 판독할 때 **맹검이 아니다** → κ는 나머지 48쌍을 주 지표로, 60쌍 전체를 참고로 보고한다.

## 1. 판정 정의

| 판정 | 같은 사진(촬영 1회)? | 같은 시편? |
|---|---|---|
| SAME | 예 | 예 — 색감·밝기·흑백·회전·반전·크롭만 다름 |
| ADJ | 아니오 | 예 — 고유 흔적으로 확인됨 (각도·위치·조명·찍힌 부위가 달라도 됨) |
| DIFF | 아니오 | 아니오 — 다르다는 증거가 있음 |
| UNSURE | 아니오 | 판단 불가 — 같다는 증거도 다르다는 증거도 없음 |

일치도(κ)는 "같은 장면(SAME+ADJ)" 대 DIFF로 계산한다. 따라서 SAME과 ADJ의 구분보다 ADJ·UNSURE·DIFF 사이의 구분이 더 중요하다.

## 2. 판정 순서 (위에서부터 처음 해당하는 단계에서 멈춤)

1. **DIFF 확인**: 장면, 접합 형태(필릿/맞대기/원주), 재질, 결함 종류가 명백히 다르면 DIFF.
2. **SAME 확인**: 회전·반전·크롭·색 변환을 되돌렸을 때 비드뿐 아니라 배경·반사광·흔적이 모두 겹치면 SAME.
3. **ADJ 확인**: 같은 사진은 아니지만, 아래 "고유 흔적"이 양쪽에서 대응하면 ADJ. 비드 구간이 서로 달라도 비드 밖의 고유 흔적이 맞으면 ADJ.
4. **나머지는 UNSURE**: 같은 시편 같다는 느낌만 있고 짚을 수 있는 고유 흔적이 없으면 UNSURE.

## 3. 고유 흔적과 일반 특징의 구분

**고유 흔적 (같은 시편의 근거가 됨)**
- 분필 글씨·표식
- 특정 위치의 스크래치, 사선 흔적
- 특이한 틈, 균열 모양
- 이음부(청색 띠·금색 구간)의 위치와 형태
- 특정 위치의 기공, 크레이터, 흘러내림 덩어리
- 모재 표면 반점 영역의 배치

**일반 특징 (같은 시편의 근거가 되지 않음)**
- 같은 지그·고정구·검은 블록·배경 (이 시편군 전체에 공통)
- 비드 끝단이 둥글거나 색이 다른 것 (파이프 둘레 비드의 공통 형상)
- 비드 폭, 모재 색, 열영향부의 전반적 색감
- "기공이 많다", "균열이 있다" 같은 결함 유형 자체

## 4. 주의 사항

- **색 차이는 판단에서 뺀다.** 색 보정이나 조명 차이로 열영향부 색이 크게 달라 보일 수 있다. 형상만 비교한다.
- **회전 방향을 먼저 정한다.** 파이프 시편은 고정구 위치로, 판재 시편은 모재 반점 영역으로 회전 방향을 정한 뒤 흔적이 그 방향대로 옮겨 가는지 확인한다.
- **흔적 하나가 안 보인다고 바로 UNSURE로 두지 않는다.** 다른 고유 흔적이 여러 개 맞으면 같은 시편으로 본다.
- **원주 용접의 이음부 유무·위치 차이는 DIFF 근거가 아니다.** 파이프를 축 방향으로 돌려 다른 둘레 구간을 찍으면 같은 시편이라도 이음부가 안 보이거나 위치가 바뀐다. 이 경우 같은 사진이 아니라는 근거만 된다.
- **콜라주**: 쌍 판정에서는 한쪽이 다른 쪽을 조각으로 포함하면 SAME. 양쪽이 모두 콜라주이면 공유 조각이 실제로 같은 사진인지 형상(경로, 덩어리, 반점)으로 확인한다. "둘 다 기공 비드"라는 것만으로는 공유로 보지 않는다.
- **그룹 판정**: 같은 사진끼리만 묶는다. 다른 묶음이 같은 조각을 공유하거나 ADJ 관계이면 메모에 적는다.

## 5. 예시

| 쌍 | 판정 | 이유 |
|---|---|---|
| A06 | SAME | 180° 회전; 금색 끝단·돌출부·곡선·고정구 위치가 함께 대응 |
| A25 | SAME | 반시계 90° 회전+색 차이; 3구간 구성·이음부 위치 대응 |
| A40 | SAME | 시계 90° 회전+확대 크롭; 반점 영역·사선 스크래치 대응 |
| A08 | ADJ | 같은 비드의 다른 구간이나 분필 표식(비드 밖 고유 흔적)이 양쪽에 있음 |
| A28 | ADJ (경계) | 하단 흘러내림 덩어리가 회전 후 형태까지 대응; 엄격 기준 시 UNSURE |
| A26 | UNSURE | 대응하는 것은 끝단 형상(일반 특징)뿐; 이음선 미확인 |
| A29·A47 | UNSURE | 같은 방향 촬영이나 한쪽에만 이음부; 다른 둘레 구간일 수 있음 |
| A30 | UNSURE | 양쪽 이음부 위치가 다름; 공통 고유 흔적 없음 |
| A51 | UNSURE | 비드 구간이 다름; 지그·배경이 같은 것은 일반 특징 |
| A57 | DIFF | 콜라주 간 공유 조각 없음; 기공 비드 조각끼리도 경로·덩어리·반점이 다름 |
| A23 | DIFF | 장면 자체가 다름 |

## 6. 출력 형식

- CSV: `id,판정,메모`
- 메모 맨 앞에 확신도 [상]/[중]/[하]를 적는다.
- 메모에는 회전·반전 방향과, 대응한 고유 흔적 또는 판단 불가의 이유를 적는다.
- 메모 안에서는 쉼표 대신 세미콜론(;)을 쓴다.
- SAME과 ADJ를 확정할 수 없으면 둘 중 하나로 적고 메모에 "ADJ 가능" 또는 "SAME 가능"을 남긴다.
- 규칙을 적용해도 갈리는 쌍은 메모에 "경계 사례"라고 적는다.
